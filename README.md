# Honghao Liu’s personal website

A static academic website built with HTML, CSS, and JavaScript. No build step or external dependencies are required.

- `index.html`: profile, news, research interests, and selected publications.
- `about.html`: education and experience; links to the full `resume.pdf`.
- `articles.html`: complete publication list.
- `contact.html`: contact links and current affiliations.
- `nav.css` and `nav.js`: shared responsive styling, navigation, and saved light/dark mode preference.

Keep the profile, CV, contact page, and publication lists aligned when updating `resume.pdf`. The portrait thumbnail is cropped from `image/photo.jpg`.

Preview locally with `python3 -m http.server 8000`, then open http://localhost:8000/.

Live site: https://hlsud.github.io/
